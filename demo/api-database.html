QuickKart — Postman API & MySQL Database

Postman Collection — 16 REST Endpoints (baseUrl http://localhost:8080)

MethodEndpointPurpose
GET/api/categoriesList categories (search, page, size)
POST/api/categoriesCreate category
PUT/api/categories/{id}Update category
DELETE/api/categories/{id}Delete category (blocked if it has products)
GET/api/productsList products (search, categoryId, page)
POST/api/productsCreate product
PUT/api/products/{id}Update product / stock
DELETE/api/products/{id}Delete product (blocked if in an active order)
GET/api/customersList customers (search, page)
POST/api/customersCreate customer
PUT/api/customers/{id}Update customer
DELETE/api/customers/{id}Delete customer (blocked if active order)
GET/api/ordersList orders (search, status, page)
POST/api/ordersPlace order (qty 1–20, stock checked)
PUT/api/orders/{id}Update order status
DELETE/api/orders/{id}Cancel / delete order (stock restored)

Postman collection file: postman_collection.json — import into Postman, set {{baseUrl}} to http://localhost:8080, run the 16 requests in order.
